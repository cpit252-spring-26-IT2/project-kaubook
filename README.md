# KauBook

## Description
KauBook is a university books and lecture notes borrowing/exchange platform designed for students.  
It helps students buy, sell, borrow, and exchange academic materials such as textbooks, summaries, and lab manuals in a simple and organized way.
The platform is built to solve common student problems such as high textbook prices, limited availability, and lack of trust during borrowing or exchange.  
It provides a structured workflow for creating listings, managing different listing types, and improving listing visibility through extra features such as verified and urgent tags.



## Features
- Create different types of listings:
  - Sell listing
  - Borrow listing
  - Exchange listing
- Unified listing model through a common `Listing` interface
- Factory Method pattern for flexible listing creation
- Decorator pattern for adding extra listing features
- Verified listing support
- Urgent listing support
- Listing validation before submission
- Listing summary generation for quick display
- Extensible design for adding new listing types in the future
- Support for academic materials such as books, summaries, and lecture notes
